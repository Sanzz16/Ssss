# Santrix Icon Pack

Paket aset Santrix yang disediakan oleh Sanzxmz.

- `icons/`: 30 pilihan ikon aplikasi (`santrix_icon_01.svg`–`santrix_icon_30.svg`).
- `banners/`: 4 banner (`santrix_banner_01.svg`–`santrix_banner_04.svg`).
- `ui_assets/`: strip kontrol, player bar, dan lembar aset asli.
- `metadata.json`: daftar ikon dengan author Sanzxmz dan tautan TikTok.

SVG dalam paket ini membungkus PNG base64 transparan; bukan path vektor yang diedit per bentuk.

## Catatan ukuran aplikasi

Mengunggah aset ke GitHub hanya menyimpan/menyediakan paket ini. APK yang telah dibuat tetap berisi ikon secara lokal, sehingga ukurannya tidak otomatis mengecil. Build aplikasi yang menggunakan icon pack lokal tetap menyertakan asetnya di APK.
